## 📊 账户状态栏

每个页面顶部都有一条状态栏，颜色和文案由服务端 `/api/status` 计算后下发
（前端不自行判断，改本地时间绕不过试用期）：

| 圆点 | 身份 | 状态栏文案 | 右上角 |
|------|------|-----------|--------|
| 🔴 红 | 未登录 | 登录以享受服务（点击去登录） | — |
| 🟡 黄 | 试用账户 | 未激活，试用期仅剩 **X天 HH:MM:SS**（逐秒递减） | 控制台 / 登出 |
| 🟡 黄 | 试用到期 | 未激活，试用期已到 + **You are blocked** 弹窗 | 登出 |
| 🟡 黄 | 管理员 | 未激活，试用期仅剩 **-1** 天（永不到期） | 控制台 / 登出 |
| 🟢 绿 | 已完成邮箱验证 | 账户正常 | **控制台** / 登出 |

- **试用账户**：由主管理员在 Cloudflare 密钥里配置账户名与密码后自动创建，试用期 7 天；
  账号密码**只存在服务端密钥中**，不写进代码，也不出现在本仓库；
- **倒计时精确到秒**：服务端下发剩余毫秒，前端换算成本地截止时刻逐秒递减
  （用「剩余量」而非绝对时间戳，客户端时钟不准也不会算错）；归零即弹窗拦截；
- **激活**＝完成电子邮件验证，激活后圆点变绿、下载不再受限；
- 试用到期后**无法下载**（服务端返回 403），须由管理员在控制台激活或续期；
- 管理员可在 `/console/` 查看全部账户、激活 / 取消激活、续 7 天。

## 🗑️ 注销账户

在 `/console/` 里，普通用户可以注销自己的账户，需**两步确认**：

1. **第一步**：输入当前密码 → 系统向绑定邮箱发送 **6 位确认码**（10 分钟有效）；
2. **第二步**：输入确认码 → 账户才真正删除。

规则与保护：

- 注销后该邮箱进入**永久不可再注册**名单（注册与发验证码都会被拦下）；
- 账户记录、邮箱索引与所有登录会话一并清除；
- **管理员**与**试用账户**不可注销（避免把管理入口或演示账号删掉）；
- 确认码连错 5 次即失效，同一账户 60 秒内只能发一次；
- 每次注销都会给管理员留一条通知：控制台显示「**最近注销 N 人**」，
  点右侧「**已读**」后该消息消失；之后再有人注销会重新出现。

## 🔧 维护时间

管理员在 `/console/` 的「维护时间」面板里选一个**时间段**（开始 → 结束）：

- **开始时间一到**：相关页面自动弹出「**正在维护服务**」弹窗；
- **结束时间一到**：弹窗自动关闭。

弹窗里是这样三行：

```
海内存知己，天涯若比邻
正在维护服务
已完成 37%
```

- 那个百分比是**按维护时间算的进度**：刚开始是 `0%`，走完是 `100%`（每秒刷新一次）；
- 弹窗底部有「**管理员关闭**」：**管理员点击会跳转到控制台**去解除维护；
  没有管理员权限的人点击则提示「**你无权进行此操作**」；
- 管理员在**控制台页面本身**不会被这个弹窗挡住，否则就没法解除维护了；
- 维护时段最长 30 天，且必须「结束晚于开始」；
- 只弹提示，不拦截接口 —— 如果你想让维护期间连下载也停掉，说一声即可。

细节：

- 面板还有「立即开始 · 30 分钟 / 1 小时 / 2 小时」快捷按钮，手机上一点就好；
- 时间到点由前端自动切换，最迟 60 秒内所有已打开的页面都会跟上。

### 只维护某几个页面（页面维护）

维护面板的时间下面有一张**页面清单**，勾哪个页面，维护的时候那个页面就进不去（弹维护弹窗），
没勾的页面一切照常：

- **一个都不勾 = 全站维护**，跟以前一模一样（老数据没有页面字段，也按全站处理）；
- 勾了的页面会弹维护弹窗；同时**导航页**上那个入口的状态灯会从 `Online` 变成红色的 `Offline`，
  维护结束后自动变回 `Online`；
- 清单内容：主站首页 / 关于开发者 / 北京时间 / 导航页 / 通知板块 / 赞助 / 资源库 / 登录 / 注册 / 控制台；
- **「联系我们」故意不在清单里** —— 它是被封禁的用户唯一能联系到管理员的地方，所以永远保持可用，
  导航页上也永远不会变成 Offline；
- 只改时间段、不重新勾选时，**勾选会被保留**（不会悄悄变回全站）；
- **输入工作人员访问密钥预览时，导航页的 `Offline` 灯不会变回 `Online`** ——
  页面确实还在维护，只是你拿着通行证能进去；
- 维护访问密钥在页面维护时同样有效：输入密钥就能进任何页面预览。

### 本次维护访问密钥（工作人员预览）

维护面板里可以顺手设一个**访问密钥**，给工作人员在维护期间进站预览用：

- 维护弹窗底部有个折叠的「**工作人员预览入口**」，输入密钥即可进入，之后这台设备在维护期间正常浏览；
- 密钥**可以随时改**：在控制台维护面板重新保存即可，改完之后旧密钥立刻失效；
- 保存时**留空 = 沿用原来的密钥**（只调整时间段不会把密钥弄丢）；
- **维护一结束，密钥随整条维护配置一起自动销毁**，通行证也同时失效；
- 密钥**不会回显**：接口只告诉你「已设置 / 未设置」，密钥本身永不下发；
- 不设密钥时，维护期间**谁都进不去**（除了管理员，管理员在控制台页面本来就不被挡）。

## 🚫 封禁账户

管理员在 `/console/` 的账户列表里，点某个账户的「**封禁**」即可封禁它。
弹窗里可以选**起止时间**：

- **结束时间留空 = 永久封禁**；填了就**到期自动解封**，不需要管理员再操作；
- 开始时间可以设在未来（先排期，到点才开始封禁）；
- 也有「1 天 / 7 天 / 30 天 / 永久」的快捷按钮；
- 服务端每次请求现算，所以到点自然失效（安卓上没有定时任务可用）。

封禁效果：

- 封禁后**立刻踢掉该账户的全部登录**；
- 被封禁的人**仍然可以登录**（这样他才能看到原因），登录后所有页面弹出
  「**You are banned**」；
- 弹窗里写明「该账户已被管理员封禁，请联系管理员」，并给出「联系我们」和
  「退出登录」两个出口；
- 该账户**拿不到任何下载链接**（服务端返回 403）；
- 列表里显示红色「已封禁」标签，顶部统计也有「已封禁」计数；
- 点「**解封**」即可恢复，解封后立即能正常下载；
- **主管理员账户不可被封禁**（否则没人能管理站点）。

## 👑 管理员分级

站点有两种管理员：

| 角色 | 谁 | 说明 |
|------|-----|------|
| 🟡 **主管理员** | 内置账户（账户名由密钥配置，不公开） | 权限最高，可设置 / 解除副管理员 |
| 🟣 **副管理员** | 由主管理员指定 | 能管普通用户、能设维护时间 |

权限对照：

| 操作 | 主管理员 | 副管理员 |
|------|:---:|:---:|
| 激活 / 取消激活 / 续期 / 封禁 **普通用户** | ✅ | ✅ |
| 设置**维护时间** | ✅ | ✅ |
| 操作**副管理员**账户 | ✅ | ❌ |
| 操作**主管理员**账户 | ❌（含自己） | ❌ |
| 设置 / 解除**副管理员** | ✅ | ❌ |

- 副管理员**不能解除其他副管理员**的管理员权限 —— 只有主管理员能做；
- 副管理员**不能激活、解封或封禁主管理员**，也不能碰其他副管理员；
- 主管理员账户**任何人都不能操作**（连主管理员自己也不行），保证站点始终有人能管；
- 被**封禁**的账户即使挂着管理员身份也**进不了后台**；
- 被**降级**的副管理员立即失去后台权限（服务端每次请求都读实时记录，不依赖旧会话）。

## 🔧 账户安全（改用户名 / 改密码）

在 `/console/` 的「**账户安全**」卡片里，普通用户可以自助修改**用户名**和**密码**，
两者都**必须通过邮箱验证码**：

1. **第一步**：填新用户名（或新密码，需输两次）→ 系统往绑定邮箱发 6 位验证码；
2. **第二步**：输入验证码 → 才真正生效。

规则与保护：

- 新用户名要满足 3-20 位（字母/数字/下划线/连字符），不能是保留名，不能与别人重复；
- 新密码**在第一步就哈希**，KV 里不会出现明文密码；
- 验证码连错 5 次失效，同一账户 60 秒内只能发一次，10 分钟过期；
- 改用户名后**本设备保持登录**，其它设备需重新登录；
- 改密码后**其它设备全部登出，本设备保持登录**；
- **主管理员不可改用户名**（它是系统入口，改名会让它失联），但可以改密码；
- 没有绑定邮箱的账户无法走邮箱验证，因此不能改；
- 被封禁的账户不能修改任何信息。

### 添加邮箱 / 更改邮箱

在 `/console/` 的「账户安全」里，还可以自助管理绑定邮箱：

| 情况 | 入口 | 需要验证 |
|------|------|---------|
| 账户**还没有**邮箱（未激活） | 「**添加邮箱**」 | 新邮箱验证码 + **密码**（验证通过即**激活账户**） |
| 账户**已有**邮箱 | 「**更改邮箱**」 | **先验证当前邮箱**，**再验证新邮箱** |

- 「添加邮箱」只验证新邮箱和密码 —— 因为账户本来就没有邮箱可验；
- 「更改邮箱」必须**两道都过**：旧邮箱的码 + 新邮箱的码，少一道都不生效；
- 不像其他操作，改邮箱**不会**把邮箱写进任何公开文件，也不影响登录会话；
- 验证码 10 分钟有效、连错 5 次失效、同一账户 60 秒只能发一次；
- 账户被封禁时不能操作邮箱。

## 🔑 忘记密码

登录页底部有「**忘记密码？**」，两种方式都能重设密码：

| 方式 | 需要什么 | 适用 |
|------|---------|------|
| **恢复代码** | 控制台里那份恢复代码 + 新密码 | 所有账户 |
| **邮箱验证码** | 绑定邮箱能收信 + 新密码 | 绑了邮箱的账户 |

### 恢复代码

格式（**区分大小写**，完整复制）：

```
key--用户名:邮箱:密码--32位随机字母数字     ← 绑了邮箱的账户
key--用户名:密码--32位随机字母数字           ← 没绑邮箱的（省略邮箱那段）
```

- 在「**控制台 → 账户安全 → 恢复代码**」里查看，**默认打码**，点「显示完整」才展开；
- 每次**设置/修改密码时自动重新生成**一份（旧的随之失效）；
- ⚠️ **代码里带着密码明文**，等于一把备用钥匙 —— 不要外传。

> ⚠️ 重要提醒：因为要「在控制台里显示给你看」，服务端必须能还原出密码，
> 所以**恢复代码是以可还原的形式存在 KV 里的**。这是这个功能固有的代价。
> 不想这样，可以把恢复代码改成「不含密码的独立随机密钥」，说一声即可。

### 几点保证

- 两种方式都会**踢掉该账户的所有旧会话**（重设密码后必须重新登录）；
- 邮箱方式 10 分钟有效、连错 5 次作废、60 秒防轰炸；
- 为了不泄露「某个账号是否存在」，账号不存在时也回同样的提示（但不会真的发信）；
- 没绑邮箱的账户走不了邮箱方式，会明确提示；
- 重设成功后新密码立刻生效，界面会自动跳回登录页并填好用户名。

## 📮 提交工单（联系我们页）

[联系我们](https://www.zrfeng.top/contact/) 页除了邮箱，还能直接**提交工单**：填标题、正文，
选填一个联系方式。**不需要登录** —— 被封禁、未激活的人正是靠这里联系管理员。

### 署名：登录 / 未登录 / 匿名

工单在控制台里的署名分三种情况：

| 提交者 | 控制台显示 |
|--------|-----------|
| 登录用户 | 用户名（`账户 xxx`） |
| 未登录访客 | `未登录用户` |
| 勾了「**匿名发送**」 | `已匿名`（橘色小标签，整条会变淡、虚线边框） |

- **匿名会降低优先级**：匿名工单统一排在**最下面**，非匿名的按时间倒序排在上面，
  方便你先处理有署名的；
- 卡片标题会顺带统计「其中匿名 N 条」；
- 勾不勾匿名都不影响别的规则：垃圾判定、一分钟一条、每天 50 条照旧；
- 说明一下取舍：匿名只是**控制台不显示**提交者（接口不下发账户名），KV 记录里仍然留着
  账户名，方便万一日后有人用匿名功能骚扰时可以追溯。**如果你想要「真的查不出来」的硬匿名，
  说一声，那只是删一行的事。**

### 垃圾工单判定

命中下面任意一条，工单会被**当场销毁**（不写 KV、不留记录、不占任何计数）：

| 规则 | 说明 |
|------|------|
| 标题少于 **3** 个字 | 空白字符不算，emoji 算 1 个字 |
| 正文少于 **10** 个字 | 同上 |
| 标题或正文**全是数字 / 标点 / 符号** | 一个汉字或字母都没有就算（纯 emoji 也算） |

页面在本地会先判一次（即时提示），服务端**一定会再判一次**（前端可以被绕过，以服务端为准）。

### 还有这些保护

- **机器人陷阱**：表单里藏了一个正常用户看不见的输入框；填了它、并且在打开页面后 **3 秒内**
  就提交（或者干脆没报耗时）的，静默丢弃并假装提交成功。真人打字总要几秒，所以就算浏览器
  自动填充了那个隐藏框也不会误伤；
- **同一 IP 一分钟一条**；
- **每天最多收 50 条**（保护 KV 免费版每天 1000 次写的额度）；
- **最多保留最近 100 条**，超出的从最旧的开始删；
- 标题最多 80 字、正文最多 2000 字、联系方式最多 100 字。

### 回复工单（历史工单也能继续聊）

工单不是一次性的，**管理员和提交者都还能继续回复**：

| 谁 | 在哪里回复 | 会怎样 |
|----|-----------|--------|
| 管理员 | **控制台 → 工单** 里每条工单的回复框 | 回复写进这条工单，「待回复」标记消失 |
| 登录用户 | **通知板块 → 我的消息** | 回复写进同一条工单，管理员在控制台能看到 |
| 未登录访客 | 同上（靠这台设备记住） | 一样能回复；**换设备或清缓存就找不到了** |

- 管理员回复后，提交者会在**通知板块 → 我的消息**收到一条通知（带工单标题和回复内容）；
- 控制台会显示每条工单有几条回复、是不是**待回复**（最后一条不是管理员发的就算待回复）；
- 有回复的工单会**被顶到列表最前面**；
- 每条工单最多保留 **50** 条回复，超出的从最旧的丢；
- 别人的工单回复不了（服务端按账户 / 设备校验，403）。

### 管理员在哪看

**控制台 → 工单**卡片：有新工单会显示「N 条新」，还有「N 条待回复」；「标记已读」后新工单提示消失；
每条可以回复、单独删除，也可以一键清空全部。正文按纯文本渲染（已转义），不会被当成 HTML 执行。

## 📢 通知板块

[通知板块](https://www.zrfeng.top/notice/) 是站点消息的统一出口，分三块：

### ① 站点公告（谁都能看）

- **维护消息会自动发到这里**：设置维护发一条（全站 / 哪几个页面、什么时候结束），
  清除维护再发一条「维护已结束」；
- 管理员也可以在通知板块页面直接**发布公告**（标题 + 正文），或一键清空全部公告；
- 主站首页原来那条公告已经搬到这里，首页只留一个入口，并顺手显示最新一条的标题。

### ② 我的消息（回复通知）

- 管理员回复了你的工单 → 这里会收到一条通知（工单标题 + 回复内容）；
- 登录用户按**账户**记，未登录按**设备**记（同一台手机/浏览器）；
- 未登录的人换设备或清缓存后，之前按设备记的消息就找不到了 —— 登录后消息跟着账户走。

### ③ 我的工单（继续回复）

- 列出你提交过的工单（含匿名提交的）和完整回复记录，可以在同一个框里继续回复。

## 🔐 登录与下载

下载链接**不存放在网页源码里**，而是保存在 Cloudflare 的服务端密钥中，
由 Worker 在确认登录后下发。因此：

- 《听潮》**不再使用任何第三方网盘**，改为**站内直接下载**
  （文件存在 Cloudflare KV 里，不进公开仓库，也不暴露任何外部链接）；
- 未登录、被封禁、试用期已到的账户**都拿不到文件**（服务端 403/401）；
- 登录 / 注册成功后跳转**主站首页**（不是小说页）；
- 注册需要邮箱验证码，仅支持 `.com` `.cn` `.net` `.top` 结尾的邮箱；
- 发送验证码前需通过人机验证（算术题，配了 Turnstile 则用 Turnstile）；
- 密码以 PBKDF2-SHA256 加盐哈希存储，会话用 HttpOnly Cookie。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript（无框架，手写）
- [Cloudflare Workers](https://workers.cloudflare.com/)：静态资产托管 + 后端接口
- Cloudflare KV：存放用户、会话、验证码与站内下载文件
- [Resend](https://resend.com/) 发送邮箱验证码
- Cloudflare DNS + 全球 CDN
- 腾讯企业邮箱
